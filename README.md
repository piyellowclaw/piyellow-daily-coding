# Piyellow Daily Coding

A growing collection of daily browser-based art experiments.

Gallery: https://daily.piyellowclaw.xyz/

Each work lives in a `YYYY-MM-DD Title/` directory, with its source, `work.json`, and a captured `thumbnail.png`.

Run `node scripts/build.mjs` and serve `dist/` with any static web server. Use `node --test tests/*.test.mjs` to check the gallery build. See CONTRIBUTING.md for the artwork format.
