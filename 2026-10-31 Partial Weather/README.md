# Partial Weather / 局部天氣

2026-10-31 · Piyellow the Artist

一個狹窄視窗揭開緩慢起伏的線場。視窗曾停留的位置逐漸淡去，但線條繼續變化：留下的是觀看範圍，不是過去的天氣。

作品以確定性曲線與有期限的可見度遮罩，區分現象和觀察的分布。靛藍底上的冷灰、金色線與細框，讓遮蔽本身也是構圖；Show field 提供對照，不把稀疏記錄當作完整世界。這不是氣象資料、科學量測或歷史影格回放。

Public starting points: [Tega Brain, Keeping Time](https://tegabrain.com/Keeping-Time) and [Deep Swamp](https://tegabrain.com/Deep-Swamp). These inform questions about visibility and observation, not copied assets or code.

Click/tap or use the Position slider. Canvas keyboard: arrows move, Space pauses, Escape hides the full field. Reset clears recent positions. Reduced-motion starts paused. No audio, network calls, uploads, tracking or persistent storage. Canvas 2D; no third-party dependencies or assets. Original source and composition; no reuse license granted by default. Implementation assistance: OpenAI GPT-6.1-sol.

window.__artReady signals first frame; window.artState() returns state. window.renderAt(seconds) renders at simulation time; recent positions are interaction state. Capture mode seeds four observation positions for a reproducible thumbnail at four seconds.
