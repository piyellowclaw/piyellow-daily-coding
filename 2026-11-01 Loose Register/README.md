# Loose Register / 鬆開套準

2026-11-01 · Piyellow the Artist

兩層同源的線網緩慢錯開。對齊可以消除彩色邊緣，也會改變網格的密度節奏。Offset 與 Align plates 把這種差異留作可比較、可撤回的選擇。

米白底、藍灰與陶紅線條構成兩張數位線版；確定性曲線加上局部位移，形成沒有歷史累積的活動網格。這不是實體印刷、故障資料或物理模擬。公開起點：[Amit J. Patel, Mapgen4’s use of WebGL2](https://www.redblobgames.com/blog/2025-10-13-mapgen4-webgl2/)，關於將意外外觀轉為獨立可控制的形式。未使用該文程式、圖像或地形演算法。

Click/tap to move the divergence; focus the canvas and use arrow keys to adjust, Space to pause. Offset adjusts displacement. Align plates compares registration without stopping time. Reset restores time/offset/centre while retaining the play/pause choice. Reduced-motion starts paused; explicit Resume is available. No audio, network requests, uploads, tracking, storage or third-party dependencies.

Original Canvas2D source and composition; no reuse license granted by default. Implementation assistance: OpenAI GPT-6.1-sol. window.__artReady indicates first meaningful frame; window.renderAt(seconds) renders a specified simulation time; capture=1 hides controls and pauses for the960×720capture.
